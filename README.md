# Educational Opportunity Model — Time and Population-Map Update

This update simplifies the dashboard around the core model and adds:

- four explicit horizons: 1 month, 6 months, 1 year, and 2 years;
- a saturating intervention-specific time-response curve;
- a visible five-vector pathway across all four horizons;
- continuous percentile interpolation for smoother projected trajectories;
- plain-language labels for PCA axes in both 2D and 3D;
- a smaller dashboard without Policy comparison, Narrative lab, or Narrative validation tabs;
- 28 passing tests.

Start with `PHASE4_7_GUIDE.md`.

The package contains no raw PISA microdata and does not replace `data/raw`, `outputs`, or `.venv`.
